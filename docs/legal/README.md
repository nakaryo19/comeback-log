# 法務ドキュメント（ドラフト）

App Store 提出に必須のプライバシーポリシー・利用規約のドラフト。
根拠は `docs/運用/商用リリース前チェックリスト.md` §1-2 および §3-1。

- [プライバシーポリシー.md](プライバシーポリシー.md)
- [利用規約.md](利用規約.md)

## 位置づけと注意

- **法律専門家のレビューを受けていないドラフト**である。公開前に、少なくとも
  消費者契約法（責任制限条項）と個人情報保護法（越境移転・開示請求）の
  2点について確認を受けること。
- 本文中の `{{...}}` は**未確定の値**。すべて埋めるまで公開してはならない。
  埋め忘れたまま公開すると、開示請求の窓口が存在しないことになる。

## プレースホルダの扱い

| プレースホルダ | 内容 | 状態 |
|---|---|---|
| `{{運営者名}}` | 開示請求の宛先となる法的主体 | 決定済み（値は非公開メモ） |
| `{{連絡先メールアドレス}}` | 開示請求・問い合わせ窓口 | 決定済み（値は非公開メモ） |
| `{{Supabaseのリージョン}}` | データの保存先 | 決定済み（値は非公開メモ） |
| `{{管轄裁判所の所在地}}` | 第一審の専属的合意管轄 | 決定済み（値は非公開メモ） |
| `{{公開URL}}` | ポリシーのホスティング先 | **保留**。GitHub Pages 等（チェックリスト §1-2） |
| `{{制定日}}` | 初版の施行日 | **保留**。App Store 提出日に確定する |

**決定済みの4項目も、本リポジトリには意図的に書き込んでいない。** 本リポジトリは公開であり、
運営者の氏名・連絡先を、公開が必要になる時点より前から検索可能な状態に置く理由がないため。
実際の値は Git 管理外のメモ（`docs/運用/商用リリース前チェックリスト.md` §1-2）に記録してある。
公開用ページを用意する段階で、まとめて差し込む。

住所の記載は本ドラフトでは求めていない。ただし将来アプリ内課金や有償提供を
行う場合は特定商取引法の表示義務が生じ、氏名・住所・電話番号の開示が必要になる。
現時点の「完全無料」方針（チェックリスト §0-A）を維持する限り、この義務は生じない。

EU 向けに配信する場合は、Apple の trader（事業者）情報として住所・電話番号の登録と
App Store 上での公開が求められる。氏名以上の開示を避けるなら、配信地域から EU を外す。
この要件は変更が続いているため、リリース直前に App Store Connect の最新要件を確認すること。

## リリース直前に必ず再確認する項目

ドラフトの内容は、確定させた時点の実装・方針を前提にしている。提出直前に次を突き合わせること。

- [ ] `{{公開URL}}` と `{{制定日}}` を確定させ、全プレースホルダが残っていないか検索する
- [ ] 「実装が前提になっている記述」（下記）が、その時点の実装と一致しているか
- [ ] 利用規約 第2条（無償提供）が、その時点の課金方針と一致しているか
- [ ] 利用規約 第7条（公開プロフィール）が、Phase 3 の実装範囲と一致しているか
- [ ] プライバシーポリシー 第6条の委託先一覧が、その時点の依存サービスと一致しているか
- [ ] App Store Connect の Privacy Nutrition Label の申告内容と、ポリシー第2条の取得情報が一致しているか
- [ ] 法律専門家のレビュー（消費者契約法の責任制限条項・個人情報保護法の越境移転）

## 実装が前提になっている記述

以下は、ポリシー本文が「できる」と書いている一方、**まだ実装されていない**。
文面を公開する時点までに実装を揃えるか、揃うまで文面を弱める必要がある。

- アカウント削除（チェックリスト §1-1）— ポリシー第8条が削除請求に応じると宣言している
- データエクスポート（チェックリスト §3-2）— 同じく開示請求の手段
- 公開プロフィール（Phase 3）— 利用規約第7条が前提にしている。Phase 3 未実装のうちは
  条文を残したままでよいが、通報窓口（チェックリスト §4）が無いまま公開機能だけ出さないこと
